## Your Task

Create or update documentation for the implemented feature:

1. **Code Documentation**
   - Ensure docstrings are complete and accurate
   - Add inline comments for complex logic
   - Update type hints if needed

2. **User Documentation** (if applicable)
   - Update README or user guides
   - Document new CLI commands or API endpoints
   - Provide usage examples

3. **Technical Documentation**
   - Document architecture decisions
   - Update API documentation
   - Note any configuration changes

4. **Release Notes**
   - Summarize what was implemented
   - Note any breaking changes
   - List known limitations

## Guidelines

- Use Read to review existing documentation
- Use Write to create or update documentation files
- Keep documentation concise but complete
- Use clear, accessible language

## Document Tracking

When you create or update any document files, report them using this format:
[DOC:filename] path: /full/path/to/filename

For example:
[DOC:README.md] path: /project/working/dir/README.md
[DOC:API_DOCS.md] path: /project/working/dir/docs/API_DOCS.md

This allows the system to track all documents generated during this phase.
